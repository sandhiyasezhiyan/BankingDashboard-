
# Banking Products Dashboard

## Project Overview
A responsive dashboard that displays multiple banking products
in a single screen.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Displays four banking products.
- Shows product name, category, status and key metrics.
- Search products by name, category or status.
- Filter products by category.
- View product details using a button.
- Responsive layout for desktop and mobile screens.

## Project Structure
- index.html - Dashboard structure
- style.css - Styling and responsive layout
- script.js - Product data and functionality
- README.md - Project documentation

## How to Run
1. Open the project folder in VS Code.
2. Open index.html using Live Server.
3. Use the search box and category filters to explore products.

## Data
The dashboard uses hard-coded sample data.
No backend or database is required.

## Note
All banking figures are illustrative sample values.
This project does not process real financial transactions.
